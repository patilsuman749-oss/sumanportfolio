# Suman Patil Portfolio

A dark, editorial-style student developer portfolio built with HTML, CSS, and JavaScript.

## Design
The layout is inspired by modern editorial/personal-brand sites: oversized typography, compact navigation, a moving topic ticker, case-study style project sections, simple data rows, and a strong closing CTA. It is an original implementation and does not copy the reference site's content.
